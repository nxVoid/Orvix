## Detailed Model & Animation Specifications

### 1. Humanoid Skeleton Standard (`CharacterArmature`)
All human characters share the standardized deformation bone hierarchy:
- **Core Spine:** `Root` → `Hips` → `Abdomen` → `Torso` → `Chest` → `Neck` → `Head`
- **Left Arm:** `Shoulder.L` → `UpperArm.L` → `LowerArm.L` → `Hand.L`
- **Right Arm:** `Shoulder.R` → `UpperArm.R` → `LowerArm.R` → `Hand.R`
- **Left Leg:** `UpperLeg.L` → `LowerLeg.L` → `Foot.L`
- **Right Leg:** `UpperLeg.R` → `LowerLeg.R` → `Foot.R`

### 2. Embedded Locomotion & Social Animation Clips
Every human model incorporates 18 animation clips directly inside its `.glb` binary chunk:
1. `Idle`: Relaxed standing idle with natural breathing motion.
2. `Walk`: Forward bipedal walking cycle with arm swings.
3. `Run`: Athletic sprint cycle.
4. `Sit`: Natural sitting posture for chairs, sofas, and seating interactions.
5. `Wave`: Friendly hand wave emote.
6. `Jump`: Upward leap.
7. `Jump_Idle`: Mid-air jump suspension.
8. `Jump_Land`: Compression landing.
9. `Punch`: Upper body strike gesture.
10. `Death`: Knockout / fall reaction.
11. `Yes`: Head nod affirmation gesture.
12. `No`: Head shake denial gesture.
13. `HitReact`: Flinch reaction.
14. Additional weapon/tool idle and motion clips.

### 3. Specialized Non-Human Skeletons
- **RobotExpressive (`robot-expressive.glb`):** 43 bones, 14 animation clips including `Idle`, `Walking`, `Running`, `Sitting`, `Wave`, `Dance`, `Jump`.
- **Fox (`fox.glb`):** 24 bones, 3 animation clips: `Survey` (idle), `Walk`, `Run`.

## Reproduction and Validation
To re-fetch and re-verify all avatar assets from pinned upstream sources, run:
```bash
node tools/relay/prepare-avatars.mjs
```
The asset validation test in `docs/3d-rooms/tests/AvatarAssets.test.ts` enforces:
1. Valid binary glTF magic header (`glTF`).
2. Exact byte length and SHA256 integrity match against `avatar-provenance.json`.
3. Self-contained buffer (no external URI network requests).
4. Skinned mesh bone count > 0.
5. Required locomotion clips (`Idle`, `Walk`/`Walking`, `Run`/`Running`).
